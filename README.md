## 💡 项目简介

**SunJK's ToolBox** 不是一款简单的笔记应用，而是一套完整的 **学习闭环系统**：

```
📥 输入 → 🤖 提炼 → 🃏 测试 → 🔍 自检 → 📊 复盘 → 🔄 迭代
```

从网课笔记、错题复盘到论文精读，它深度融合 AI 能力（总结、闪卡、解题、自检），让每一份输入都转化为扎实的认知资产。无论你是考研党、考证族，还是终身学习者，这款工具都能成为你的 **第二大脑**。

### 设计哲学

- **数据主权**：所有数据本地存储，API 密钥由你掌控，绝不云端偷窥。
- **AI 增强而非替代**：AI 是辅助思考的伙伴，不是替你思考的机器。
- **渐进式复杂度**：从简单的记录开始，逐步解锁深度功能，学习曲线平缓。
- **多端协同**：手机记录，平板阅读，WebDAV 桥接两端。

### 🤖 AI 智能总结 – 三种模式，按需深度

| 模式 | 适用场景 | 特点 |
|:---|:---|:---|
| ⚡ **标准模式** | 日常笔记、短文 | 快速生成概括，响应迅速 |
| 🔗 **检索增强模式** | 浅层记录、碎片信息 | 自动补全背景知识，扩展关联内容 |
| 🧠 **多 Agent 模式** | 网课字幕、整本讲义 | 分块 → 逐块总结 → 整合，保证长文本质量 |

- **模型选择**：`v4 flash`（轻快） / `v4 pro`（深度）
- **可视化渲染**：输出 **MD + HTML 混合格式**
  - 🔵 **概念** → 蓝色底色
  - 🔴 **易错点** → 红色底色
  - 🟡 **重点** → 黄色底色
- **重新生成**：不满意可随时重新生成，支持切换模式

### 🔍 自检模式 – 像 Steam 评论区一样遮罩测试

> 灵感来源于 Steam 评论区「剧透」效果

- AI 自动识别总结中的 **关键知识点**
- 用 **色块隐藏** 关键内容
- 点击色块 → 显示真实内容
- 用于 **自我测验记忆效果**，比单纯重读更有效

### 📝 错题添加与 AI 解题

**添加方式**：
- 手动输入题目
- 📷 拍照 / 选择图片

**AI 解题流程**：
1. AI 自动拆解题目
2. 自动匹配相关学习记录的 AI 总结内容（基于标题、科目相似度）
3. 利用匹配知识解题并生成解析
4. 解析格式同样支持 MD+HTML 渲染（概念/易错/重点颜色标注）

## 🚀 快速开始

### 前置准备

1. 申请 [DeepSeek API Key](https://platform.deepseek.com/)
2. 申请 [和风天气 API Key](https://www.qweather.com/)（可选）
3. （可选）准备坚果云 WebDAV 账号用于同步（可选）

### 克隆与构建

```bash
# 克隆项目
git clone https://github.com/your-username/SunJK-ToolBox.git
cd SunJK-ToolBox

# 构建 Debug APK
./gradlew assembleDebug

# 或直接安装到设备
./gradlew installDebug
```

### 首次使用

1. 进入设置 → 配置 DeepSeek API Key
2. 创建第一个笔记本
3. 添加第一条学习记录
4. 体验 AI 总结、闪卡生成等功能
